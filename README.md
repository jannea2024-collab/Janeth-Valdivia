# Wiki Janeth Valdivia

Enciclopedia pública del rastro documentado de **Janeth Valdivia Pérez**: investigación, comunidad y field-building de AI Safety en México. Solo fuentes abiertas. Metodología y exclusiones de homónimos van dentro del sitio.

## Correr en local

```bash
npm install
npm run dev
```

El sitio queda en `http://localhost:5173`.

## Publicar

```bash
npm run build
```

La carpeta `docs/.vitepress/dist` se puede servir en GitHub Pages, Netlify o Cursor. En GitHub Pages, apunta el source a esa carpeta o usa el workflow de VitePress.

## Criterio editorial

Ver `docs/metodologia.md`. Si un hecho no tiene URL, no entra.
